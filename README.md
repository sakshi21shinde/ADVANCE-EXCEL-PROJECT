# Global Supply Chain Disruption & Logistics Performance Analysis

## 📌 Project Overview

The **Global Supply Chain Disruption & Logistics Performance Analysis** project focuses on analyzing supply chain operations and identifying the major factors affecting delivery performance, shipment delays, and transportation costs.

The project uses Microsoft Excel to transform raw logistics data into meaningful insights through data cleaning, formula-based analysis, PivotTables, charts, and an interactive dashboard.

The main objective is to understand delivery performance, evaluate the impact of external disruptions such as geopolitical risks and weather conditions, and identify areas for improving logistics efficiency.

## 🎯 Project Objectives

- Analyze overall supply chain and logistics performance.
- Identify on-time and delayed deliveries.
- Analyze shipment delays across different transportation modes.
- Evaluate the impact of geopolitical risks and weather severity.
- Compare shipping costs across product categories and routes.
- Identify patterns and trends in logistics operations.
- Build an interactive dashboard for better decision-making.

## 📊 Dataset Description

The dataset contains approximately 10,000 shipment records with the following attributes:

| Column Name | Description |
|---|---|
| Order_ID | Unique shipment identification |
| Origin_City | Shipment starting location |
| Destination_City | Shipment destination |
| Route_Type | Type of transportation route |
| Transportation_Mode | Mode of shipment |
| Product_Category | Category of shipped products |
| Base_Lead_Time_Days | Expected standard delivery time |
| Scheduled_Lead_Time_Days | Planned delivery time |
| Actual_Lead_Time_Days | Actual delivery time |
| Delay_Days | Number of days delayed |
| Delivery_Status | On-time or delayed status |
| Geopolitical_Risk_Index | Geopolitical risk level |
| Weather_Severity_Index | Weather disruption severity |
| Shipping_Cost_INR | Shipping cost in Indian Rupees |
